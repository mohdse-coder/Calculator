# 🧮 ماشین حساب ساده | Simple Calculator

یک ماشین حساب مدرن، ساده و کاربردی که با استفاده از HTML، CSS و Vanilla JavaScript خالص ساخته شده است. این پروژه از طراحی واکنش‌گرا (CSS Grid) و مدیریت State تمیز با استفاده از `data-*` attributes بهره می‌برد.

### ✨ ویژگی‌ها (Features)
*   **عملیات ریاضی پایه:** انجام چهار عمل اصلی (جمع، تفریق، ضرب و تقسیم).
*   **پشتیبانی کامل از کیبورد:** تایپ اعداد و عملگرها، دکمه `Enter` برای مساوی و دکمه `Esc` برای پاک کردن.
*   **طراحی مدرن:** استفاده از CSS Grid برای چیدمان دکمه‌ها (دکمه مساوی و صفر به صورت اختصاصی طراحی شده‌اند).
*   **مدیریت خطا:** جلوگیری از وارد کردن چندین ممیز (اعشار) در یک عدد.

# 🧮 Simple Calculator

A clean, modern, and functional calculator built with pure **HTML**, **CSS**, and **Vanilla JavaScript**. It features a responsive Grid layout and clean state management using `data-*` attributes.

### ✨ Features
*   **Basic Arithmetic:** Supports Addition, Subtraction, Multiplication, and Division.
*   **Full Keyboard Support:** Type numbers/operators, press `Enter` to calculate, and `Esc` to clear.
*   **Modern UI:** Styled with CSS Grid (custom layout for the "=" and "0" buttons).
*   **Input Validation:** Prevents multiple decimal points in a single number.
